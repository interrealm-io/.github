InterRealm designs, deploys, and stewards resilient digital infrastructure for public education systems. We believe that public educational standards, competencies, and curriculum mappings should function as open utilities — free from restrictive vendor lock-in, proprietary API gatekeeping, and central points of network failure.

---

## 🏛️ Our Governance & Core Principles

Everything engineered under the InterRealm organization adheres to a strict architectural blueprint designed for maximum field resilience:

*   **Radical Minimalism (Zero-Dependency Engineering):** We build core infrastructure using programming language standard libraries wherever possible. This eliminates IT procurement bottlenecks and protects school districts from security supply-chain vulnerabilities.
*   **Edge Sovereignty & Offline Parity:** Educational software shouldn't stop working if an upstream server or ISP goes down. Our tools prioritize local execution on commodity hardware with zero data-sync compromise.
*   **Data Integrity Over Inference:** A tool that silently guesses an answer is worse than one that returns nothing. We build deterministic tracking frameworks that make data boundaries, inference steps, and structural drift completely transparent.
*   **High-Fidelity Federation:** We design networks using name-based, deterministic primitives (like `UUID v5`) so independent regional instances achieve global data parity automatically, eliminating the need for costly identity reconciliation layers.

## 🚀 Active Ecosystem Infrastructure

### 🌐 [Learning Net](https://github.com/interrealm/learning-net)

*A self-hostable mirror, Model Context Protocol (MCP) server, and explorer for the Learning Commons Knowledge Graph.*

> *Commons is the collection. Net is the distribution.*

Learning Net brings a complete, topology-aware network of **283,381 nodes and 492,169 edges** covering all 52 US K-12 academic jurisdictions directly onto a local machine.

*   **AI-Native Integration:** Serves as a pure Python standard library MCP server, allowing LLM agents (Claude, Cursor, custom runtime tools) to reason over US curricular standards with zero network latency or API rate limits.
*   **Auto-Bridging Logic:** Automatically resolves hidden hub-and-spoke multi-state topology paths, explicitly flagging bridged lookups to prevent AI hallucinations.
*   **Frictionless Distribution:** Builds the entire national graph in about forty seconds on stock district Python — no package manager, no account, no API key.
*   **Measurable Verifiability:** Ships `coverage_report` and `verify_alignment_claim` — the first public measurement of how much of the national standards corpus carries a checkable cross-jurisdiction alignment. Today: **9.5%**.

*Learning Net is an independent project. It is not affiliated with, endorsed by, or operated by the Chan Zuckerberg Initiative or Learning Commons.*

## 🗺️ Shared Open Roadmaps

InterRealm infrastructure focuses on shifting open public datasets from isolated centralized collection pools into fully distributed, actionable networks:

1.  **Local Extension Protocols:** Engineering isolated, namespaced multi-table architectures so school districts can map localized curriculum variations safely without getting clobbered by upstream releases.
2.  **Federation Tooling:** Standardizing schema merge-semantics across independent trusted instances using predictable, cryptographic secure-mapping.
3.  **Upstream Drift Reporting:** Building open diagnostic engines that capture structural database mutations, feeding changelogs directly back to upstream aggregators.
